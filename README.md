# The Cleaving Hooves

A cinematic Vite + React project with a Mongol-inspired battle campaign.

## Run locally

1. Install dependencies:
   npm install

2. Start the app:
   npm run dev

3. Open the local URL shown by Vite in the terminal, usually:
   http://localhost:5173

## Production build

npm run build

## Preview production build

npm run preview

## Hosting notes

- The app is configured for static hosting and uses a relative base path.
- For GitHub Pages or similar static hosting, run the build and upload the generated dist folder.
- The dev server is exposed on all interfaces so it can be accessed from the local network or a host environment.
